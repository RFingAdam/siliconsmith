## Rules

1. GPL tools (Icarus, KLayout, Xschem, netgen, openEMS, Elmer, and any other GPL tool we add) are only ever called as **separate processes**. Never import, link, or copy their source into this repo.
2. LGPL (MyHDL; Verilator as a process; ngspice subcomponents we never link) is fine as an unmodified dependency or external binary. Keep MyHDL an optional extra.
3. This repo contains no tool source or binaries. The Docker image is a separate distribution artifact and must ship a copy of this file plus source links (GPL requires source availability when we distribute binaries; using distro packages that already ship source is the easiest route).
4. If a license cannot be verified from the official source, do not add the tool until it can.
